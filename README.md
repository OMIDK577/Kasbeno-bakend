# Kasbeno Bot 💰

Kasbeno is a Telegram earning bot with a 24-hour mining system, lucky wheel, tasks, referrals, wallet and advertising features.

## Features

- ⛏️ 24-Hour Mining System
- 🎡 Daily Lucky Wheel
- 🎯 Tasks and Rewards
- 👥 Referral System
- 💰 User Wallet and Balance
- 💸 Withdrawal Requests
- 🌐 Multi-language Support:
  - Dari
  - Pashto
  - English
- 🛡️ Anti-Fraud System
- 📊 Admin Panel
- 📢 Advertising and Monetization System
- 📈 Revenue and Profit Tracking

## Technology

- Python
- Telegram Bot API
- SQLite
- HTML
- CSS
- JavaScript

## Project Status

Kasbeno is currently under active development.

## Important

Points in the development version are virtual rewards. Real-money withdrawals will only be enabled after the advertising revenue and payment systems are properly connected.
